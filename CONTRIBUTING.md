# Contributing

Read `AGENTS.md` first — it applies to humans too.

- Substantial changes start from a spec: see `docs/spec-driven-dev.md`.
- Routine PRs target `dev`. Conventional Commits, no AI co-author trailers.
- Run format, lint, typecheck and the relevant tests before opening a PR.
- Do not add dependencies or abstractions without a real need; do not copy code from AGPL or proprietary sources.
- Chinese and English are both fine in issues and PRs.
- External contributions require a signed CLA (individual or corporate; see `docs/adr/adr-002-license-and-business-model.md`). Until the CLA bot is live, external PRs are reviewed but not merged.
- The code is Apache-2.0. The Tenon name and logo are not covered by the license; do not ship modified builds under the Tenon name.
