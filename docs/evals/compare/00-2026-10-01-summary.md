## 看到的客户端差异

1. **审批范围**（[已知差异 #1](../README.md#已知差异清单)）：Tenon 写入每个文件本会话问一次，命令按原文本会话问一次，只读命令也问。B 的 8 道任务题每题在开始时弹「允许更改该文件夹」「允许本次 Cowork 会话访问该文件夹」各 1 张，之后读、改、跑命令都没有卡（01、16 改了源码，15 改了 plan.json，其余写了输出文件）。这与 2026-09-28 补录的结论一致，仍只限这些操作和授权条件。
2. **长输出**（03，H9）：Tenon 把超过阈值的输出落盘，给预览和路径（A、C 各落盘 84 932 字节）；Claude Code 在这一次非零退出的结果里只把约 1 万字的开头交给模型（只观察到这一次），模型因此多跑了命令；把日志写到 /tmp（工作区外）是模型自己选的。Cowork 怎样处理，录屏看不到。
3. **同一文件第二次编辑**（15）：Tenon 一张写入卡管到会话结束；D 的驱动对每张卡都选一次性 Yes，Claude Code 第二次编辑同一文件又问。
4. **拒绝即结束本轮**（16，[已知差异 #10](../README.md#已知差异清单)）：C 在第 2 轮弹出 1 张工作区外卡，测试宿主只能拒，Run 以 user-rejected 结束，题目 fail。复跑定性：卡上是模型抄错的长临时路径（漏字或错字），真的不在工作区里，Tenon 判定正确（见 16 的对比）。
5. **请求量**：C、D 同入口同单价，同 9 题（去掉 01）C 合计 ¥0.667，D 约 ¥1.93；D 的 transcript 缓存读约 56 万 token，C 约 11 万。其中 C/16 只跑了 2 轮就被拒结束（约 ¥0.02，D/16 约 ¥0.30），差距有一部分来自这题的结局；去掉 16 的 8 题 C 约 ¥0.648、D 约 ¥1.63。客户端每次请求带的系统提示和工具定义不同，本次没有逐条拆分。

## B 怎么判的

- 只读证据目录，把 `ws/` 复制到临时目录后按各题检查复算：JSON 键序无关的精确比较、在副本里跑 `node test.mjs`、01 与 16 的隐藏探针。「输入未改」逐字节对仓库夹具，并与 fixture-initial / fixture-final 两份 sha256 互核：初始哈希与仓库夹具一致，最终哈希与 ws 里的文件一致；题面与仓库 tasks 逐字相同。
- 要 Tape 的条件（01 第 4 条「改完后跑过测试且通过」、16「模型跑过 node test.mjs 且输出 pagination passed」）本列没有 Tape 或转录：依回复自述与录屏步骤标签判 pass，记录里注明未经核验。03 的落盘统计只适用于 Tenon，B 不适用。
- 18、20 对保存的回复原文按 `jsonReply` 的规则判：去掉代码围栏后比数据。20 的回复带 json 围栏。
- `durationMs` 取 README 的观测上限；`toolRounds` 拿不到，记 null，界面显示的工具数写在 note 里；`raw` 是录屏文件名和锚点秒数。

## 不可比的地方

- **答卡方式**：A、C 由测试宿主自动答（`command`、`default` 允许，卡上有「本会话」就选它，`outside-workspace` 只能拒）；B 每张文件夹卡点一次 Allow，不勾「不再询问」；D 的命令与写入都选一次性 Yes。卡数差里有一部分来自这些选法。
- **用时**：A、C 是运行器的墙钟，不含人工；D 是首条用户消息到 turn_duration 的墙钟，含人工审批等待；B 是含点卡与人工观察延迟的上限。只能看量级。
- **effort**：A、C 不传（模型默认档）；B、D 界面为 High。A 与 B 同模型，但档位不一定相同。
- **上下文窗口**：D 对未知模型按默认 200K；Tenon 的评测专用 glm-5.3 行是 1M。
- **次数与时间**：每列每题 1 次，做法上的差异（跑脚本还是直接写）不归给客户端。D 的 01 是 09-28 跑的，其余都在 10-01。
- **版本**：B 用 Desktop 2.9939.2（界面提示待更新 v2.16120.0，未更新）；[已知差异 #8](../README.md#已知差异清单) 已补记这次的版本。
- **B 在哪执行**：本次会话访问卡写着「Because this task runs in the cloud, files Claude uses leave your device and are processed on Anthropic's servers」，步骤标签写「Ran a command on your computer」。命令和文件操作实际在哪执行，本次没有核实；产物落在本机连接的副本目录里。
