## 差在哪

- **A 与 B**：输出相同，两份输入都与夹具逐字节相同。A 经命令写文件，2 张命令卡；B 只有 2 张文件夹卡。
- **C 与 D**：输出相同，输入都没改。C 读完后用 Write 写，1 张写入卡；D 先跑 ls、读两份输入（都免问），再用一条 python3 命令合并并写出，1 张命令卡。

## 原因

- 审批范围（[已知差异 #1](../README.md#已知差异清单)）：Claude Code default 模式对 ls 这类只读命令免问，Tenon 只读命令也问；Cowork Manual 在已连接的文件夹里没有逐次卡。本题 C 没有跑命令，所以只读命令这一条在 C 与 D 之间没有体现成卡数差。
- C 写文件、D 用命令写，是同一模型在两个客户端里的不同做法；只跑 1 次，不归给客户端。
